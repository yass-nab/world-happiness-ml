# World Happiness Report - Data Science & Machine Learning

End-to-end data-science project on the World Happiness Report: from cleaning and feature engineering to clustering, classification, explainability and statistical testing.

## What I did
- Built an end-to-end ML pipeline with smart imputation and feature engineering.
- Applied **KMeans clustering** to group countries with similar well-being profiles.
- Tuned classification models inside **scikit-learn Pipelines**.
- Used **SHAP** explainability to interpret which factors drive happiness predictions.
- Ran statistical hypothesis tests on the happiness indicators (SciPy).

## Tools
Python - Pandas - NumPy - scikit-learn - SHAP - SciPy - Matplotlib - Seaborn - Jupyter Notebook

## Project structure
```
world_happiness_analysis.ipynb   # full pipeline: EDA -> features -> clustering -> models -> SHAP -> tests
data/World Happiness Report.csv
requirements.txt
```

## Run it
```bash
pip install -r requirements.txt
jupyter notebook world_happiness_analysis.ipynb
```

World Happiness Report (public dataset).
